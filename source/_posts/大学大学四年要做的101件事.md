**大学四年要做的101件事**
# 情感

*因为丰沛的情感。我们的生命有了色彩:爱情是炽烈的攻红色，亲情是温柔的嫩绿色，友情是淡雅的鹅黄色，与陌生人之间的温情，则是深邀的海蓝色.....在理智的画笔下，这些色彩重叠交融，又错落有致在人生的画卷中铺陈开来。*

- [ ] 真诚热烈地恋爱一次，无论结果如何
- [ ] 写一封情书，给挚爱的人
- [ ] 毕业之前，告诉你喜欢的人：“我爱过你！”
- [ ] 尝试着送花给自己心仪的女孩子
- [ ] 当你确信自己喜欢一个人，就大声对他（她）说出来，不要害怕被拒绝
- [ ] 挑选一份心爱之物珍藏起来，无论价值厚薄
- [ ] 假期回到故乡，到儿时玩耍的地方走一走
- [ ] 每年献一次血，为他人提供帮助，为自己储蓄健康
- [ ] 了解父母的健康状况，假期陪他们去体检或健身
- [ ] 每年生日，给父母写封信，感谢他们将你带到这个世界上
- [ ] 假期回到家里，学会做菜，为父母做一次完整的晚餐
- [ ] 参加一次葬礼，体味生命的可贵
- [ ] 每年参加一次公益活动
- [ ] 大学四年至少帮助一个人，提供力所能及的帮助
- [ ] 做一次环保志愿者
- [ ] 安排与父母及家人一起去旅行
- [ ] 假期回家，拜访曾经教过自己的老师，与他们聊聊天
- [ ] 为年迈的父母按摩、擦身
- [ ] 用自己赚的钱给父母买一份礼物，无论价格高低
- [ ] 为灾区及慈善机构募捐
- [ ] 遇到突发事件时，第一时间给父母打电话报平安
- [ ] 做一次家教，帮助一个孩子成长
- [ ] 为父母或家人筹划一次生日晚会
- [ ] 自己设计一张贺卡，寄给亲人和朋友
- [ ] 当与父母产生隔阂时，主动与父母沟通
- [ ] 搜集家谱，了解家族的渊源

# 学习

*从牙牙学语时，我们便开始了对生命的探索。真理就像是昼伏夜出的太阳，挑衅着我们的神经。但学习中的快乐和满足，让我们不顾冰冷的黑夜，跌跌撞撞地追逐远处的阳光。*

- [ ] 大学一年级，做好一份人生职业规划
- [ ] 至少学好一门外语，最好是能说会听
- [ ] 从第一学期开始，充分了解学校历史与名人
- [ ] 从大学第一学期开始，制作一份个人成绩记录表
- [ ] 做一次测验，发现自己的性格、兴趣和特长
- [ ] 阅读相关书籍，掌握一定的记忆、阅读方法
- [ ] 组织一次读书会
- [ ] 拟订一个阅读计划，开列四年必读书目
- [ ] 向报纸杂志投稿，争取一年发表一篇文章
- [ ] 毕业前，写一部个人自传
- [ ] 每年为自己做一本照片专辑
- [ ] 发挥想象力，写一篇童话
- [ ] 每年坚持听20次讲座，获得更多的思想和知识
- [ ] 认真扎实地写好毕业论文，给四年所学一次完美的总结
- [ ] 每年给自己颁发一个“奖”——自我激励
- [ ] 至少学会一种乐器，增加一种技能
- [ ] 要求自己每周必须去一次图书馆
- [ ] 每年独自拜会一次辅导老师，听听他对你的看法和建议

# 习惯

*习惯是潜伏在我们生活中的细菌，好的习惯是有益菌，坏的习惯是病菌。它们悄无声息地存在，偶尔大张旗鼓地出现，便能影响我们的生活。没有人只有好习惯或者只有坏习惯，但是我们可以选择哪种习惯更多一些。*

- [ ] 每个月整理一次电脑，将不用的东西清理掉
- [ ] 每年清理一次房间，摆脱不需要的东西
- [ ] 早睡早起，养成健康的学习、生活习惯
- [ ] 每天读30分钟的课外书，养成终身阅读的好习惯
- [ ] 开始写日记，记录自己四年生活历程
- [ ] 坚持写博客，建立自己的网络朋友圈
- [ ] 坚持每天锻炼30分钟，养成健身好习惯
- [ ] 召集同学每月彻底打扫一次寝室，养成讲卫生的好习惯
- [ ] 每月用一天来冥思，体验生命
- [ ] 利用7天时间改掉一个坏习惯
- [ ] 每日反省自己的过失之处
- [ ] 致力于完成每一项承诺，养成诚信的习惯
- [ ] 每月整理一次学习任务，将拖延的事情做完，养成高效的学习习惯
- [ ] 从进入校园第一天开始存钱，养成节俭的习惯
- [ ] 学会做学习、工作计划表

# 交往

*我和你，你和他，他和她，通过交往，我们连成了一张网，捕捉着懵懂的悸动，捕捉着青春的张狂。最初，我们对这张网存在的意义可能不够了解，但我们分明感受到，因为它，我们筛出了遗憾，精致了生活。*

- [ ] 交几个能同患难、共祸福的朋友
- [ ] 读几部人际交往方面的书籍，掌握为人处世的学问
- [ ] 与同寝室的同学和睦相处
- [ ] 参加一个社团，争取成为组织领导者
- [ ] 鼓起勇气拜见一位心中最景仰的名人
- [ ] 给那些你曾经讨厌的人写封信
- [ ] 与他人合作完成一件事
- [ ] 当自己犯错时，真诚地向对方道歉
- [ ] 在校园里，或者在旅行中，尝试与陌生人交流
- [ ] 拜见校长或系主任，说出你对学校的看法
- [ ] 组织一次高中同学聚会
- [ ] 通过网络交一个异地或异国的朋友
- [ ] 在公共场合做一次讲演
- [ ] 与那些优秀的人建立联系并虚心向他们学习
- [ ] 四年假期里，与同学一起回家，拜访他的父母
- [ ] 结识一位学长或学弟，听取他们的意见，或者给予他们一些建议
- [ ] 认真观察自己周围的人，给他们一个新的评价
- [ ] 毕业前，跟有过节的同学说声对不起，尽释前嫌

# 体验

*雨后的彩虹和窗外的北风;漂亮的女生和白发的先生;喧闹的赛场和静谧的教室;快乐的节日和闲适的假期......我们的生活中永远不缺乏值得体会的事情，缺乏的只是一颗蠢蠢欲动、充满激情的心。*

- [ ] 看一次大海，体验海阔天空、心潮澎湃的感觉
- [ ] 到山顶看一次日出日落的壮丽景观
- [ ] 看一看古代遗迹，感受历史
- [ ] 选择一个自认为不可能的事情，向自己的个性进行一次挑战
- [ ] 每个月骑车在学校所在的城市到处游历，熟悉自己学习的城市
- [ ] 认真逛一次自己的校园，发现那些美丽的角落
- [ ] 通过拜会同学的方式，到周围其他学校看看，感受异校的风情
- [ ] 做一件与自己个性迥然不同的事，让人刮目相看
- [ ] 给自己一个四年中的旅行计划，假期独自去旅行
- [ ] 培养一种业余爱好
- [ ] 每年就社会问题或者自己感兴趣的问题做一次调查
- [ ] 三年级和四年级外出打工，培养自己工作能力
- [ ] 尝试做几次小生意，看看自己是否有经营能力
- [ ] 一周不吃肉，做一次环保体验
- [ ] 做一份商业计划书，并向风险投资商推介，无论成功与否
- [ ] 每年去面试一次，了解各种职业的整体需求和对个人能力的需求
- [ ] 到一个陌生城市，自己独立生存一段时间
- [ ] 在大庭广众之下表演，树立信心
- [ ] 为自己种下一棵树，每年都去照顾它，看着它成长
- [ ] 做一次农民或者建筑工人
- [ ] 参加一次学生干部竞选
- [ ] 以独特的方式迎接新年的到来
- [ ] 许下一个愿望，毕业的时候检验这个愿望实现没有
- [ ] 养一盆花，或者一个小动物，培养自己的爱心
