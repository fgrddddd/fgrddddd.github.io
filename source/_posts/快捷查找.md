# 勾选框
{% cb text, checked?, incline?, disabled? %}
text：显示的文字
checked：默认是否已勾选，默认 false
incline: 是否内联（可以理解为后面的文字是否换行），默认 false disabled: 勾选框是否为不可点击的样式，默认 false
